Coin is Select on Nintendo systems. NES games use only B and A. Most Genesis games use Y, B and A.

Hold Coin and press…

Coin + StartQuit the game (and save your progress) Coin + RSave state: a snapshot of right now Coin + LLoad that snapshot Coin + BRestart the game Coin + XEmulator menu

Arcade games

CoinInsert a credit (free, press as often as you like) Start1-player game A + R2-player game (insert 2 credits; take turns)
Don't lose your save!
Games marked S save only when you quit with Coin + Start. Switching off mid-game throws it away. For P games, write the password down. Save states (Coin + R) are a handy backup.
